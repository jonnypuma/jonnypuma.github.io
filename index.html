Skippy Repo 1.0.4

Install the Kodi repository

Install the repository once. Kodi then lists the add-ons under Install from repository and keeps them up to date.

  1. In Kodi, open Settings › System › Add-ons and allow Unknown sources.
  2. Open Settings › File manager › Add source and enter this address:
    https://jonnypuma.github.io/repository.skippyrepo/
  3. Open Add-ons › Install from zip file, pick that source and choose repository.skippyrepo.zip.
  4. Open Add-ons › Install from repository › Skippy Repo and install what you need.

Or download the zip and install it from a USB stick or a network share: repository.skippyrepo-1.0.4.zip

Curator · Docker

Run Curator with Docker

Curator builds from its repository with Docker Compose and starts with its own PostgreSQL database. You need Docker with Compose and Git.

  1. Get the code:
    git clone https://github.com/jonnypuma/curator.git && cd curator
  2. Make your own copies of the two example files:
    cp docker-compose.yml.example docker-compose.yml && cp .env.example .env
  3. Open .env and set MUSIC_PATH, MOVIES_PATH and TV_PATH to your library folders. The folders must already exist.
  4. Start it. The first start builds the image, so it takes a few minutes:
    docker compose up -d
  5. Open http://<host>:4455. On a new install the setup wizard opens by itself and takes you to the first scan.

On Windows use copy instead of cp. Curator keeps its settings in the config and data folders next to the compose file, so keep them in your backups. About Curator · Full instructions
